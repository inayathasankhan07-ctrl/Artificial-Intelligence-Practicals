# Artificial Intelligence Practicals – Unit 1 & Unit 2

Welcome to my **Artificial Intelligence Practical Repository**. This repository contains practical programs implemented using **Prolog** as part of the **B.Tech Computer Science and Engineering (AI & ML)** curriculum.

The repository covers **Unit 1 – Introduction to AI and Intelligent Agents** and **Unit 2 – Problem Solving and Searching**. It includes implementations of knowledge representation, recursion, list operations, graph searching, heuristic search, optimization algorithms, constraint satisfaction problems, and backtracking.

## 📚 Units Covered

- **Unit 1:** Introduction to AI and Intelligent Agents
- **Unit 2:** Problem Solving and Searching

## 🛠️ Technologies Used

- **Programming Language:** Prolog
- **Prolog Environment:** SWI-Prolog
- **Code Editor:** Visual Studio Code (VS Code)
- **Version Control:** Git and GitHub

## 🚀 How to Run the Programs

Follow these steps to execute the practical programs:

1. Install SWI-Prolog on your computer.
2. Clone or download this repository.
3. Open SWI-Prolog.
4. Navigate to the folder containing the practical file.
5. Load the required Prolog file.

**Example:**

```prolog
?- ['01_student_course_database.pl'].
```

Run a query after loading the file. For example:

```prolog
?- enrolled(inayat, Course).
```
